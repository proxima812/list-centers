# Чек-лист ручной проверки после фиксов ревью (v13.1.67–69)

Прогонять на проде или на превью деплоя. Отметки: `[x]` — проверено, ок;
`[!]` — найдена проблема (описать рядом).

## 1. EN-версия: битые ссылки (критичное, было массовое 404)

- [ ] На `/en/` в шапке кликнуть **Projects** — должна открыться русская
      `/projects/` (раньше — 404 на `/en/projects/`).
- [ ] На `/en/` в футере и в мобильном меню ссылка Projects — тоже `/projects/`.
- [ ] Бейдж «Новый пост» на `/en/` ведёт на русскую страницу поста (не 404).
- [ ] Бейдж «Новый центр» на `/en/` — если последний центр не переведён,
      ведёт на русскую карточку `/centers/tbk-N/`.
- [ ] На EN-странице центра (например `/en/centers/tbk-40/`) пагинация
      «пред./след.»: непереведённые соседи ведут на русские карточки,
      переведённые — на `/en/centers/…`.
- [ ] «Печать .pdf» в выпадающем «Прочее» на EN-странице ведёт на
      `/centers/print/` (русская, но существует).
- [ ] Переключатель языка:
  - [ ] на русском посте `/posts/<slug>` → EN ведёт на `/en/` (не 404);
  - [ ] на непереведённом центре (tbk-367…tbk-400) → EN ведёт на `/en/centers/`;
  - [ ] на переведённом центре → EN ведёт на `/en/centers/<id>/`;
  - [ ] на `/projects` → EN ведёт на `/en/`.
- [ ] `/en/policy`, `/en/sources`, `/en/translations`, `/en/thanks` —
      мгновенный редирект на русские версии (meta-refresh, это норма для
      статики), русский текст под `lang="en"` больше не отдаётся.

## 2. Markdown-ссылки (критичное)

- [ ] `/policy` — ссылка лицензии показывает текст **«CC BY 4.0»**, а не
      «creativecommons.org».
- [ ] Открыть 2–3 поста и карточки центров: у ссылок с авторским текстом
      (`[текст](url)`) виден именно текст, домен — только у ссылок без текста.

## 3. Поиск каталога `/centers`

- [ ] Поиск «казань» → очистить крестиком → **порядок карточек вернулся к
      исходному** (по дате), не остался «по релевантности».
- [ ] Открыть по прямой ссылке `/centers?q=казань` — выпадашка подсказок
      **не открыта** сама по себе; появляется при фокусе в поле.
- [ ] Набрать 2–3 буквы и мгновенно нажать «сбросить фильтры» — запрос не
      «воскресает» через долю секунды (инпут и выдача остаются чистыми).
- [ ] На `/en/centers` поиск **«Saint Petersburg»** находит карточки
      (работает JSON-индекс с локализованными терминами).
- [ ] Поиск по названию района (например «Авиастроительный») находит центр.
- [ ] Клавиатура в подсказках: стрелки ходят по списку, Enter выбирает,
      Escape закрывает.

## 4. Тема / акцент / анимации

- [ ] Переключить акцент green → blue → violet: фокус-обводка (Tab по
      карточкам каталога, /saved, /projects) везде акцентного цвета.
- [ ] Тумблер «анимации выкл»:
  - [ ] кнопка «наверх» скроллит мгновенно, без smooth;
  - [ ] закрытие мобильного меню возвращает скролл без «проезда» страницы;
  - [ ] смена темы не кросс-фейдится (мгновенно);
  - [ ] лента слов на главной (marquee) стоит.
- [ ] Системный «уменьшить движение» (без тумблера сайта): marquee тоже стоит,
      якорные ссылки скроллят без smooth.
- [ ] **Safari, «Блокировать все куки»**: сайт открывается без вспышки/поломки,
      переключатели темы/акцента/моушена работают (в пределах вкладки).
- [ ] Две вкладки: смена темы в одной подхватывается второй; очистка
      localStorage в одной — вторая возвращается к дефолтам.

## 5. Меню и навигация

- [ ] Мобильное меню: «Политика» — в секции «Правовая информация»,

- [ ] Переключатель языка с клавиатуры: стрелки вверх/вниз ходят между RU и

- [ ] Кнопка «копировать страницу»: при успехе — галочка; по HTTP/без

- [ ] Меню «Open in ChatGPT/…» — пункты открывают платформу даже до

## Известное, не чинилось (не удивляться)

- `/en/policy` и другие EN-заглушки отдают HTTP 200 + meta-refresh, а не
  настоящий 301 — ограничение статического вывода Astro.
- 404-страница всегда русская, в т.ч. для `/en/*`-путей.
- Ссылки вида `[текст](url "title")` и URL со скобками в секции «Ссылки»
  карточек центров пока не разбираются (`centerLinks.ts`).
- Хабы `/` ↔ `/en/` и `/centers` ↔ `/en/centers` не связаны hreflang.
- `TechStacks` нигде не рендерится (только экспортируется) — иконки
  заинлайнены «на будущее».
