# tatarverse UI Tailwind

Проектный скилл для небольших UI-изменений. Для аудитов, редизайнов и
крупной дизайн-работы бери `impeccable` - он читает `PRODUCT.md`,
`DESIGN.md` и сайдкар.

## Перед правкой

1. Прочитай `DESIGN.md` и `.impeccable/design.json`. Они авторитетнее любого
   дизайнерского инстинкта и обязаны совпадать между собой: меняешь одно -
   меняй второе.
2. Посмотри существующий компонент и соседние использования.

## Три пользовательские оси, которые обязана пережить любая поверхность

- **Акцент** - шесть пресетов (`green`, `blue`, `violet`, `red`, `orange`,
  `pink`), атрибут `[data-accent]` на `<html>`. Единственный список -
  `src/utils/accents.ts`, палитры - `src/styles/palettes/*.css`.
- **Тема** - light / dark / system, класс `.dark`.
- **Анимации** - тумблер `[data-motion="off"]` плюс
  `prefers-reduced-motion`. Подробности - в скилле `tatarverse-motion`.

Никаких литеральных hex и сырых палитр Tailwind (`text-blue-500` и подобных):
только семантические токены из `src/styles/tailwind.css`
(`background`, `surface`, `surface-muted`, `foreground`,
`muted-foreground`, `subtle-foreground`, `border`, `border-muted`, `ring`,
`accent*`, `destructive`, шкала `depth-100 … depth-700`).

## Workflow

1. Используй утилиты Tailwind v4 и существующие паттерны компонентов.
2. Геометрия - `rounded-*` + `corner-squircle` там, где это уже принято;
   радиус в этом проекте часть пресета акцента, см. `design.json`.
3. Контейнеры - через `Container` / `not-container`, max-width не выдумывай.
4. Не добавляй CSS-файлы и зависимости: единственная точка входа стилей -
   `src/styles/tailwind.css`.
5. Держи адаптив явным для изменённого компонента.
6. Проверь переполнение текста, размер тач-таргетов, фокус с клавиатуры и
   семантику разметки затронутой поверхности.
7. Для визуальных изменений - точечная проверка в браузере или скриншот,
   если dev-сервер уже поднят или его легко поднять.

## Вывод

Опиши, какая поверхность изменилась и как проверялась - включая поведение
в тёмной теме и при выключенных анимациях, если правка их касается.
